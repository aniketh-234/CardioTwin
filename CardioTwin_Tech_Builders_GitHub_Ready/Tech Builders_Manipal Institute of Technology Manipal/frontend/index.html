Evaluation contract

Patients never overlap across the 60 / 20 / 20 split. Preprocessing uses training patients only. Early stopping uses validation Brier score. The simulator’s latent variables and probabilities never enter the feature matrix.

The original Synthea sample is a separate source audit. Its small number of future events cannot support these benchmark claims. Wearable readings in this benchmark are generated together with a coherent hypothetical outcome process.

Next evidence needed: a matched longitudinal clinical cohort, endpoint adjudication, external validation, calibration and subgroup evaluation before any clinical use.
